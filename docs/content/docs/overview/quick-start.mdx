# 快速开始

当前二开版本必须同时运行 `server/` 和 `web/` 构建产物，不能只部署静态前端。

## Vercel 部署

当前登录、SQLite 和服务端渠道代理需要常驻 Bun 服务及持久化数据目录，不再支持只通过根目录 `vercel.json` 完成正式部署。

## 本地启动

```bash
git clone <你的仓库地址>
cd infinite-canvas
cd server
bun install
cp .env.example .env
bun run dev
```

另开一个终端：

```bash
cd web
bun install
bun run dev
```

启动后访问：

```text
http://localhost:3000
```

## Docker 启动

如果你需要基于当前源码构建镜像：

```bash
docker build -t infinite-canvas .
docker run --rm -p 3000:3000 \
  --env-file ./ops/runtime.env.example \
  -v infinite-canvas-data:/app/data \
  infinite-canvas
```

## 首次使用建议

- 不要直接使用示例环境文件上线。先生成独立的 `APP_ENCRYPTION_KEY`，并设置首次管理员账号和强密码。
- 使用管理员账号登录后，在“管理”中配置 Base URL、API Key、允许模型和能力类型。
- 确认管理员能够登录且数据卷已持久化后，从服务器环境文件中移除首次管理员密码。
- 如果需要提示词仓库内容，打开 `/prompts` 会由浏览器前端直连拉取并缓存到 IndexedDB。
- 如果需要跨设备同步画布、素材和生成记录，可在配置弹窗中填写 WebDAV。

## 说明

- 当前画布项目和“我的素材”主要保存在浏览器本地，WebDAV 同步需要用户自行配置。
- AI API Key 由服务端加密保存，普通用户无法从模型配置接口读取真实密钥。
