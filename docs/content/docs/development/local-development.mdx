# 本地开发

当前主应用由 `server/` 和 `web/` 组成。服务端负责登录、用户管理、渠道密钥加密和 AI 请求代理；前端负责画布与工作流。

## 1. 配置并启动服务端

```bash
cd server
bun install
cp .env.example .env
bun run dev
```

首次启动前需要在 `.env` 中设置：

- `APP_ENCRYPTION_KEY`：32 字节随机值的 Base64 编码。
- `BOOTSTRAP_ADMIN_USERNAME`：首次管理员用户名。
- `BOOTSTRAP_ADMIN_PASSWORD`：首次管理员密码。

服务端默认监听：

```text
http://localhost:3001
```

## 2. 启动前端

另开一个终端：

```bash
cd web
bun install
bun run dev
```

前端默认访问：

```text
http://localhost:3000
```

开发服务器会把 `/api` 代理到 `http://127.0.0.1:3001`。

## 3. 配置模型

使用首次管理员账号登录，打开“管理”，创建服务端渠道并填写 Base URL、API Key、允许模型和能力类型。普通用户只会看到允许使用的模型。

## 4. 启动文档站

如果需要单独调整文档站，在 `docs` 目录执行：

```bash
bun run dev
```

## 常见场景

- 改画布、页面和交互：主要看 `web/`
- 改登录、账号、渠道和 AI 代理：主要看 `server/`
- 改提示词缓存：主要看 `web/src/services/api/prompts.ts`
- 改文档站内容：主要看 `docs/content/docs/`
