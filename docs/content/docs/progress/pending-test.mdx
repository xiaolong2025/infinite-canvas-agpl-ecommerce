# 待测试

- AI 多模态大请求与图片反推修复：文本模型视觉输入会在浏览器内生成不覆盖原资产的压缩副本，单图和多关键帧共享约 560KB 原始图片预算；Nginx 模板同时只对 `/api/ai/` 放宽到 64MB。反推输出必须包含主体、构图、镜头、光线、色彩、材质、风格、背景八维拆解，以及完整中文生图提示词、比例、清晰度与质感、禁止内容。点击反推结果的生图入口后，新配置节点必须同时继承原始图片和最终提示词；生图模型未启用 `image-ref` 时应明确阻止生成，不能静默退化为纯文字生图。前端遇到 413 或 Nginx HTML 错误页时应显示中文错误，不再把 HTML 写进文本节点。部署后需用截图中的同一张 1254×1254 商品图验证生成结果仍是黑色街头 T 恤人物，不得变成精灵或其他无关主体。
- 三案请求修复：生成或重新生成 3 个剧情钩子前必须确认产品资料中至少有一张可读取的参考图，并确认文本模型已开放 `image-ref`；请求体由统一视觉输入压缩处理。部署后需验证首次生成和“重新生成 3 案”都不再返回 Nginx 413，并确实返回正好 3 个方案。
- 登录与服务器托管 API：本地已通过前后端 TypeScript、Vite 生产构建和 Bun API 测试，覆盖未登录拦截、会话登录、管理员创建用户、渠道密钥不回传、普通用户安全模型配置和代理路径白名单。仍需在 Docker 镜像中验证 SQLite 持久化、真实管理员登录、Gemini/Kedaya/ZZ 渠道配置、有限额度真实请求和蓝绿回滚。
- 开发版自动部署：本地已创建用户自有 GHCR workflow、服务器 Compose、3100/3101 双槽位部署脚本、独立 Nginx 站点模板、`/healthz` 和 `/build-info.json`。TypeScript、生产构建、Compose 展开、workflow YAML、Bash 语法和 Nginx 模板替换已验证；Docker Desktop 未运行，因此镜像构建、容器健康检查、真实 Nginx 切换、服务器预检、公网域名和回滚仍未验证。
- 部署版本识别：本地生产构建会生成 `build-info.json`，页面版本弹窗显示构建 SHA；正式镜像需要用完整 Git SHA 构建，并确认候选端口与公网 `/build-info.json` 都返回同一 SHA。
- YigeAI 部署保护：生产容器保留三个同源代理路径，部署脚本要求切换前后访问不含 Key 的 `YIGEAI_HEALTH_URL`。正式验收仍需确认 `api.yigeai.work` 的健康地址、入口机与 API 源站隔离，以及部署期间 API 容器 ID/启动时间没有变化。
- 视频节点「拆解对标」：上传一条本地可播放视频，填写可选的市场/产品复刻要求，确认浏览器能抽取最多 8 个关键帧、文本模型收到带时间标记的关键帧并返回中文 Markdown；成功后应在视频右侧创建「对标视频拆解」文本节点并自动连线。需在已配置支持图片输入的文本模型后人工验证，当前未触发真实模型调用。
- 拆解后电商工作流：选中「对标视频拆解」节点，确认「生成新剧本」能打开产品资料表单，并在完成产品参考图和事实填写后按顺序创建 3 个剧情钩子、完整销售剧本、结构化分镜、角色基准图和完整故事板。当前只完成入口与表单的浏览器验收，未触发真实模型或生图调用。
- YigeAI Gemini 调用链：重启本地 Vite 后，配置页的 Gemini 文本渠道应能通过 YigeAI 代理拉取模型；选择 `gemini-3-flash-preview` 执行一次有限范围视频拆解，确认不再出现本地 `404`，并确认返回结果能落为「对标视频拆解」文本节点。真实模型调用可能产生费用，需单独确认后执行。
- 全站 Agent：新增 `generation_get_status` 工具，画布生成节点可按 `nodeIds` 查询，生图和视频工作台提交后会返回 `taskId` 并可查询排队、运行、成功或失败状态；需验证查询只由当前活动标签页返回。
- 本地 Agent 多标签页隔离：同时打开两个不同画布并连接同一个 Agent，分别聚焦标签页后通过 MCP 读取和修改画布，操作应只落在当前聚焦页面；网页面板发起的整个 Codex turn 应固定操作发起页面，即使中途聚焦另一标签页也不能切换目标；关闭当前页面后应回退到最近聚焦且仍连接的页面，其他页面回传同一请求结果应被拒绝。
- 本地 Agent 多标签页会话同步：所有标签页共享同一个站点级 Codex 活跃线程；任一页面发送消息、新建、恢复或删除会话后，其他页面应同步活跃线程和聊天记录；Agent 输出仅显示在事件所属线程，运行中不能新建、恢复、删除或再次发送任务。
- 本地 Agent 运行状态同步：在一个标签页运行较长 Codex 任务，等待某张工具卡显示「工具完成」后再打开或刷新第二个标签页；第二个标签页应立即显示 Codex 正在运行并禁用发送，整轮结束后两个标签页同时恢复；工具卡只显示「工具完成」，整轮结束由「本轮完成」表示。
- 本地 Agent 图片附件落画布：在右侧 Agent 上传参考图并要求基于商品信息创建生图流程，附件应创建为保持原比例的真实图片节点，分析提示词应创建为文本节点，二者都应连接到生成配置节点；刷新页面后参考图仍可显示并参与生成。任务中途切换到其他标签页时，附件只能写入发起任务的标签页；若发起标签页关闭，附件读取应失败且不能落入其他画布。
- Agent 对话滚动：从历史或日志切回对话、恢复其他会话时应自动定位到最新消息；手动向上浏览后应显示向下箭头且新消息不强制打断阅读，点击箭头后平滑回到底部并继续跟随新消息。
- Agent 消息区分：用户消息应在右侧以主题浅底气泡显示，AI 回复应在左侧保留 Agent 图标并使用开放式 Markdown 排版；长文本、多张附件、错误消息及浅色/深色主题下均应清晰且不溢出。
